# 勾配ブースティング(GBDT)をイメージで理解する 全体像編  
  
### 1.モデルの全体像と意味合い  
**GBDTの目的：**  
特徴量空間内の「位置と値の関係性」を「分割エリアごとの予測値」として表現する。  
  
**抽象的な学習イメージ：**  
損失関数によって、「何を重視して予測を合わせに行くか」という基準をあらかじめ設定する。その基準のもと、位置と正解値を持つサンプルデータ点を手がかりとして、空間内のエリア分割と予測値の調整を繰り返していく。  
  
**最終的な予測モデルの姿：**  
特徴量空間を、各軸に沿って細かくエリア分割し、各エリアに予測値を持たせたようなモデルになる。  
  
  
### 2.「空間内のエリア分割」と「予測値の調整」について  
**エリア分割の基本操作**  
特徴量空間内のエリア分割とは、「あるエリアに属するサンプルデータの集合を、損失が最も減る形で2つのグループに分ける」という操作である。二分割後の各エリアには、そこに属するサンプル集合をもとに算出された最適な更新値(予測値)が、それぞれ割り当てられる。  
  
**特徴量の性質によって変わる、分割方法と見た目のイメージ**  
この「2つに分ける」という操作自体はどの特徴量でも共通しているが、分割の仕方と、そこから受ける視覚的なイメージは、特徴量の性質によって異なる。  
- 数値特徴量：軸は連続値が並ぶ数直線。値そのものに大小関係があるため、「ある閾値より大きいか小さいか」で分割する。エリアをスパッと一箇所で切り分けるイメージ。  
- カテゴリ特徴量：軸は、順序を持たないカテゴリがただ並んでいるだけのもの。値の並びそのものには意味がないため、カテゴリを2グループに振り分けて分割する。分割結果は、元のカテゴリの並びで見ると飛び飛びの縞模様(シマウマ状)になるイメージ。  
  
  
  
### 3.モデルのもう少し具体的なイメージ  
**モデルの成り立ちの仕組み：**  
特徴量空間にまず初期値を適用し、そこへブースティングによって作られた多数の決定木の出力を学習率で調整しながら順に重ねて(足して)いく。その結果、各決定木の分割を組み合わせた細かなエリアごとに、最終的な予測値が定まる。  
  
**注意点：**  
- 決定木を深くしすぎたり本数を増やしすぎたりすると、データ点1つ1つの周りだけに小さな孤島のような極小エリアが乱立し、ノイズまで学習してしまう(＝過学習)。  
- 学習データの外側では、端のエリアの予測がそのまま外側へ続くため、値の変化の傾向を延長して予測するのは苦手(＝外挿が苦手)。
