# 大規模NNとGBDTのざっくり比較

## 概要

### 主に扱うデータ

| 大規模NN | GBDT |
| --- | --- |
| 表形式ではないデータ(非構造化データ)。テキスト、画像、音声、動画など。 | 表形式データ(構造化データ)。スプレッドシート、Excel、DBテーブル、CSV、TSVなど。 |

### モデルの出力

| 大規模NN | GBDT |
| --- | --- |
| 人間が五感で理解できる情報（テキスト、画像、音声、動画）や、数値（確率など）。 | 数値（予測価格、発生確率、スコアなど）のみ。 |

### AI界での立ち位置

| 大規模NN | GBDT |
| --- | --- |
| 勾配ブースティングと共に、現代AIを支える二本柱の1つ。非構造化データ学習におけるデファクトスタンダード。 | ニューラルネットワークと共に、現代AIを支える二本柱の1つ。構造化データ学習におけるデファクトスタンダード。 |

### モデルの汎用性

| 大規模NN | GBDT |
| --- | --- |
| ただ一つの汎用モデルを構築する世界。<br>非構造化データ（テキスト、画像、音声、動画など）に共通する普遍的な性質を学習するため。 | 要件ごとに個別の専用モデルをゼロから構築する世界。<br>表データの構造が業務要件ごとに全く異なり、他への流用が原理的にできないため。 |

## 仕組み

### 学習のイメージ

| 大規模NN | GBDT |
| --- | --- |
| 特徴量空間内の座標に、画像・自然言語・音声・動画などの情報群をデータ点として配置してから、意味の近いデータ点同士が近くに集まるように、空間を変形させていく。 | 特徴量空間内の座標に、特定の表データの各行をデータ点として配置してから、意味の近いデータ点同士が同じエリア内に含まれるように、空間を格子状に細分化していく |

### 空間の扱い方

| 大規模NN | GBDT |
| --- | --- |
| パン生地をこねるように、空間をグニャグニャに変形させる。※変形させたものは潜在空間と呼ばれる。 | 豆腐をさいの目切りするように、空間をブロックに切り刻んで分割する |

### 完成したモデルのイメージ

| 大規模NN | GBDT |
| --- | --- |
| 空間を変形させる「こね方の手順（レシピ）」。 | 空間を分割する「切り方の手順（レシピ）」と、細分化された各エリアに割り当てられた「予測値」。 |

### 推論のイメージ

| 大規模NN | GBDT |
| --- | --- |
| まっさらな特徴量空間内の座標に、予測したい情報をデータ点として配置してから、その空間をレシピと全く同じ手順でこねていく。 | まっさらな特徴量空間内の座標に、予測したい情報をデータ点として配置してから、その空間をレシピと全く同じ手順で切っていく。 |

### 予測結果

| 大規模NN | GBDT |
| --- | --- |
| 予測データ点が最終的に着地した「空間の座標」を答えの形に変換した値。 | 予測データ点が最終的に属する「空間のエリア」にあらかじめ割り当てられている値。 |

### 予測根拠の説明のしやすさ

| 大規模NN | GBDT |
| --- | --- |
| 特徴量空間をグニャグニャに変形するため、元の特徴量のスケールと意味が破壊され、ブラックボックスになる。 | 空間を一切歪めず「元の座標軸に平行な切断」しか行わないため、元の特徴量のスケールと意味が保持され、特徴量ごとの影響度を通じた納得感のある説明が可能。 |

### 斜めの関係性(特徴量同士の連動)の捉え方

| 大規模NN | GBDT |
| --- | --- |
| 空間そのものを自在にこねる（回転・歪曲させる）ことで、複雑な斜めの関係性を空間の柔軟な歪みとしてしなやかに表現できる。 | 複雑な斜めの関係性を捉えるには、直交する区切りを階段状に大量に配置しなければならず、空間表現として非効率になる。 |

### トレードオフ

| 大規模NN | GBDT |
| --- | --- |
| 「空間を回転・変形する自由」を手に入れた代わりに、「元の座標軸の意味(解釈性)」を失った。 | 「空間の変形を禁じ、座標軸を守った」代わりに、「斜めの関係の表現効率」を犠牲にした。 |

### 必要な数学のレベル

| 大規模NN | GBDT |
| --- | --- |
| 大学教養課程レベル | 大学教養課程レベル |

### 裏で使われている数学

| 大規模NN | GBDT |
| --- | --- |
| 線形、非線形写像：空間をこねる操作<br>連鎖律：空間のこね方の調整 | 偏微分：各学習データ点ごとの誤差を測る<br>テイラー展開：空間を切る位置の基準を作る |
